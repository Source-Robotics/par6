# Getting help

Where to ask, in the order that gets an answer fastest.

## Before you ask

1. Search this documentation (the search box at the top).
2. Check the [FAQ](faq.md) and the Troubleshooting chapter of the manual you are in.
3. For a robot problem, make a **support bundle** first: Dashboard → Logs → *Support bundle*. It packs the logs,
   the incident recordings and the configuration files into one archive; nearly every question about a robot
   needs it. [How to](../rcb/07-operating/logs.md)

## Bugs and mistakes

- A mistake in these pages: every page ends with **Edit it on GitHub** (a pull request) and **Report it** (an
  issue with the page already filled in). [More](contributing.md)
- A bug in the robot software, the firmware or the hardware: [Report a problem](report-a-problem.md)
