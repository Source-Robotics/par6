Each tab in the header is one document: the arm, the control box, programming, the dashboard, the end
effectors, simulation, and support. Inside a document, the left sidebar lists its chapters and reference
sections; the right sidebar lists the headings of the open page. The logo returns to the PAR6 Hardware Manual.

Hardware manuals (the arm, the end effectors) are revised with the hardware and do not depend on the software
version. The Control Box Manual, the Programming Guide and the Dashboard Guide describe one runtime version each;
the dropdown next to the site name switches between versions, and a page from an older version says so in a bar
at the top. The repository card on the right of the header opens the source of whatever the open page describes.
Every page ends with two links: one to edit the page, one to report a problem with it.
