# Error and event codes

Every error, warning and event the robot reports has a number and a name, for example `2103 WATCHDOG`. A joint's
code carries the joint in front of it, for example `J3:WATCHDOG`. The dashboard, the activity log, the Python
client's exceptions and the status messages all show the same number and name, so a code from any of them can be
looked up here.

This page is generated from the runtime's error catalog at the release this documentation describes.
