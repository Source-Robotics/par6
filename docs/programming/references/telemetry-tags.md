# Telemetry tags

A telemetry recipe lists the tags the robot sends in each state packet. Each tag below is one value or one value per
joint; *Decimals* is how many decimal places it is sent with unless the recipe says otherwise. Values marked RAW
are the measured signals; their filtered twins end in `_f`.
